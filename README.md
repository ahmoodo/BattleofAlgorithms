# BattleofAlgorithms
Bitminers

Run the base Battleship code:
1) cd "(insert your file path here)"
      Note: if the command terminal is using your C: drive and the project is on you D: drive, run the code cd /d "(file path)"
2) python3 -m venv .ven
3) .\.venv\Scripts\activate
4) pip install -r requirements.txt
5) python3 main.py

The problem:
Our project will test several algorithms against each other to determine which one is superior in battleship.

Objectives:
1- Create a digital form of a battleship.
2- Optimize the two players to be both AI algorithms.
3- Determine the winner

End Goal:
  Helping human players determine the best methodology of playing Battleship based on the visual aid produced as a report. 

Algorithms:
1- MinMax algorithms
2- Reverse Manhattan 
3- A* algorithms 
4- Dijkstra's
